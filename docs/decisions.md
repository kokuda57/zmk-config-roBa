## エンコーダのスクロール方式（2026-06-20）

決定: default 層のエンコーダは矢印キー行スクロール `&inc_dec_kp UP_ARROW DOWN_ARROW`。1ノッチの行数は `roBa.dtsi` の
`triggers-per-rotation` で調整し、足りなければ1トリガで複数行送るマクロにする。

理由:
- 「1ノッチで1/3ページ」は厳密にはキーボード側でできない（1ページの行数がアプリ・ウィンドウで変わる）。近似のみ
- PG_UP / PAGE_DOWN は1ページ固定のキーなので、1/3ページなどページ未満の移動はできない。ページ未満で動かすにはマウスホイールのスクロールにする必要がある
- 矢印キーは離散の keypress なので確実に動き、暴走しない

採らなかった案:
- `&msc`（マウススクロール）を `zmk,behavior-sensor-rotate`（v0.3 に存在）経由で使う案。`&msc` は押している間スクロールし続ける時間ベースの動きで、
  エンコーダと相性が悪い。tap-ms=5ms では無反応、30ms では押しっぱなし扱いで暴走し、安定する幅が狭く実用にならなかった
  （参考: SCRL_UP=MOVE_Y(10) で量はゼロではない）

## トラックボールの automouse を無効化（2026-06-21）

決定: `config/roBa.keymap` の `automouse-layer` を `<4>`→`<(-1)>` にした。

理由: 文字入力中の微振動で MOUSE 層（4）へすぐ切り替わり、J=MB1 / K=MB3 / L=MB2 が誤クリックになっていた。
主な原因は超高感度の設定（roBa_R.conf: MOVEMENT_THRESHOLD=0, AUTOMOUSE_TIMEOUT_MS=700）。-1 ならドライバの
`#if AUTOMOUSE_LAYER > 0` のガードに掛かり完全に無効になる。

影響: MOUSE 層（4）へ行くキーはほかに無いが、クリックの手段は別に用意してあるので問題ない。
トラックボールはセントラル＝右手が処理するので、右手 roBa_R へ書き込む。
